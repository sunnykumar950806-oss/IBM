🛡 MITRE ATT&CK Alert Mapper

A defensive cybersecurity tool that helps Security Operations Center (SOC) analysts and students understand how security alerts map to the MITRE ATT&CK Enterprise Framework.

This project is for defensive purposes only — security monitoring, threat detection, and incident investigation. It does not implement or assist with attacks, exploitation, or malware.

How It Works
1. You submit a security alert (text or JSON)
↓
2. The parser extracts indicators (IP, user, process, command line…)
↓
3. The mapping engine scores each MITRE technique by keyword matching
↓
4. Top techniques are returned with confidence scores
↓
5. Investigation steps and Sigma rules are shown for each technique
